README：CityWalk - PROG2001 A2 3D Interactive Project
This is the GitHub repository for PROG2001 Assessment 2 — a team-based 3D interactive Unity project named CityWalk.

---
1. Project Overview

CityWalk is a top-down/third-person 3D collection & obstacle game.

Players control a character to explore 4 themed maps, collect coins, avoid heart-losing obstacles, and reach the container finish line to win.


---
2. Core Gameplay

- The player starts with 3 hearts

- Touching specific obstacles → lose 1 heart

- Collect coins throughout the level

- Reach the container checkpoint → win (regardless of coin count)

- Lose all 3 hearts before reaching the container → game over
